# 真政治

公平、公正、透明地揭露台灣政治資訊的平台，讓所有人都能看到正確、可查證的資訊。

## 三個原則

1. **公正**：不偏袒任何政黨或人物，所有候選人用同一套標準與版面。
2. **可查證**：每一筆查核都附上公開來源。
3. **透明**：判定標準、資料格式與修改紀錄都公開。

## 第一版功能：辯論逐字稿查核

- 兩位候選人的逐字稿依辯論環節左右並列（可一鍵左右對調，手機上改為上下排列）。
- 被查核的句子會劃線並標出判定，點開可看：
  - **數據查核**：正確／部分正確／錯誤／無法查證，以及查核過程
  - **執行所需費用**：估算金額與估算依據
  - **實際會遇到的問題**
  - **公開來源連結**
- 每位候選人的查核統計表，可依判定篩選。

> ⚠️ 目前 `2026 臺北市長候選人辯論會（第一場）` 的逐字稿與查核內容全部是**範例**，只用來示範版面與資料格式，網頁上也明確標示。辯論日期與流程取自 ETtoday、公視的公開報導。

## 怎麼看

網頁用 `fetch` 讀取 JSON，需要透過伺服器開啟（直接雙擊 `index.html` 會讀不到資料）：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

純靜態網頁，不需要建置步驟，可直接部署到 GitHub Pages、Cloudflare Pages 等。

## 資料格式

```
data/
  index.json                      # 所有辯論的清單
  debates/
    2026-taipei-mayor-1.json      # 一場辯論一個檔案
```

### 新增一場辯論

1. 在 `data/debates/` 新增一個 JSON 檔（可複製現有檔案修改）。
2. 在 `data/index.json` 的 `debates` 加一筆 `{ id, title, date, file }`。
3. 執行 `node tools/validate.mjs` 檢查格式。

### 辯論檔欄位

| 欄位 | 說明 |
|---|---|
| `id`、`title`、`date`、`format` | 辯論基本資訊 |
| `isSample`、`sampleNote` | 是否為範例資料；為 `true` 時網頁會顯示提示 |
| `debateSources` | 辯論本身的公開來源（錄影、官方逐字稿） |
| `candidates` | `{ id, name, party }`，陣列順序就是預設的左右順序（建議依抽籤順序） |
| `sections` | 辯論環節 `{ id, title }`，依時間順序 |
| `utterances` | 發言段落 `{ id, speaker, section, text, time?, sample? }`，`text` 必須是逐字原文 |
| `claims` | 查核項目，見下表 |

### 查核（`claims`）欄位

| 欄位 | 說明 |
|---|---|
| `id` | 唯一代號 |
| `speaker`、`utteranceId` | 發言人與所屬段落 |
| `quote` | 被查核的句子，必須與 `text` 中的文字**完全相同**，網頁會自動劃線 |
| `topic` | 議題（居住、交通、育兒、財政…） |
| `verdict` | `correct` 正確、`partly` 部分正確、`incorrect` 錯誤、`unverifiable` 無法查證 |
| `summary` | 一句話結論 |
| `analysis` | 查核過程與數據比對 |
| `cost` | `{ estimate, basis }` 執行費用估算與依據 |
| `challenges` | 實際執行會遇到的問題（字串陣列） |
| `sources` | `{ title, publisher, url }`，至少一筆 |
| `checkedAt` | 查核日期（`YYYY-MM-DD`），未正式查核為 `null` |
| `sample` | 是否為範例 |

## 公正性做法

- 兩位候選人的欄位用相同版面、相同中性配色，刻意不用常與政黨聯想的藍、綠作為主色。
- 判定標準公開於網頁上，所有發言適用同一套標準。
- 查核只針對可驗證的事實與數字，不評論立場。
- `tools/validate.mjs` 會列出每位候選人的查核筆數，差距過大時提醒檢查選題是否一致。

## 要把範例換成真實內容，需要的來源

- **逐字稿**：主辦電視台的完整錄影（以錄影為準逐字聽打），或主辦單位／媒體公布的完整逐字稿（例如 ETtoday 文字直播）。
- **財政與預算**：臺北市政府主計處預算書與決算書、審計部審核報告。
- **各政策數據**：臺北市資料開放平臺，及社會局、都發局、都市更新處、交通局、臺北捷運等主管機關公布的統計。
- **候選人政見與經費**：各陣營正式公布的政見與經費估算。
- **議會紀錄**：臺北市議會質詢與議事紀錄。
